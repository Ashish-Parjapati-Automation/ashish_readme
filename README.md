## 🤖 Current personal project

**Agentic Orchestrator Monitor** — TypeScript AI agent that autonomously monitors UiPath Orchestrator job health.

- Polls Orchestrator API → evaluates job state → sends contextual email alert → kills stuck jobs via API
- Kill thresholds based on real production failure patterns (Terminating >5 min, Queue jobs >10 min, etc.)
- LLM (LLaMA via Groq) generates natural language alerts and handles ambiguous job states
- Stack: TypeScript · Groq SDK · LLaMA · UiPath Orchestrator API
